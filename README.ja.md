風が強いのはどの辺りか、夜になるとどれくらい冷え込むか。地図を動かしながら、気になる地域の天気を調べられます。韓国気象庁の予報に加え、大気の状態や道路カメラも確認できます。

地図の操作画面は現在、韓国語のみです。このページでは、画面上で見つけやすいように韓国語のメニュー名も載せています。表示時刻はすべて韓国標準時（KST、UTC+9）で、日本との時差はありません。

## 風の流れと強さを見る

動く線は風向き、地図の色は風速を表します。色が濃いほど風が強い場所です。具体的な風速は、画面下の色分けの目盛りや、地点を選んだときの数値で確認できます。

![風向きと風速を表示する地図](docs/media/wind-streamline.gif)

## 時刻を変えて、天気の変化を確かめる

画面下で時刻を変えると、同じ地域の気温や風、雨の予報を見比べられます。再生ボタンを押すと、予報が順に切り替わります。

![時刻を変えながら見る気温の予報](docs/media/timeline-play.gif)

## 行きたい場所の48時間予報

地域名で検索するか、地図上の場所を選ぶと、48時間先までの予報が開きます。グラフで大まかな変化を見て、その下のカードで毎時の気温・降水確率・湿度・風を確認できます。詳しい数値を一覧表で見ることもできます。

![釜山の48時間の風の予報と時間ごとの天気](docs/media/station-timeseries.webp)

## 大気の状態と道路の様子も

**대기질** を選ぶと、AirKoreaの観測地点が表示されます。地点を選ぶと、PM10・PM2.5の濃度、区分、観測時刻を確認できます。

大気のデータは**最新の観測値**です。予報時刻を変えても濃度は変わらず、重ねて表示している風の予報だけが切り替わります。

![PM2.5の観測地点と、濃度・観測時刻の表示](docs/media/air-quality.webp)

**교통** を選んで地図を拡大すると、道路カメラを探せます。カメラを選び、再生ボタンを押すと映像に接続します。配信元の接続状況によっては見られない場合があります。

## 地図をもっと使いやすく

- **色分けの目盛りを開く**と、詳しい区分と最小・平均・最大値が表示されます。
- **等値線**で、予報の値が同じ場所を線で結んで表示できます。
- **距離測定**では、地点間の直線距離や、複数の区間の合計を調べられます。
- **地図だけの表示**にすると、操作パネルを閉じて広く見渡せます。
- **共有リンク**には、表示中の場所・天気の種類・予報時刻が保存されます。
- **3D表示**では、気象データを高さで表したり、地球儀上に表示したりできます。高さは実際の地形や標高を表すものではありません。

キーボードでは、`/` で地域検索、`F` で地図だけの表示への切り替え、`Esc` で開いているパネルを閉じられます。

## データの提供元

予報・気象特報・台風・落雷は**韓国気象庁**、大気の観測値は **AirKorea**、道路映像は韓国の**国家交通情報センター（ITS）**のデータを使っています。観測値や映像は更新が遅れたり、一時的に利用できなくなったりすることがあります。荒天時の判断には、[韓国気象庁の公式発表](https://www.weather.go.kr/)も確認してください。

画面例は2026年9月22日に撮影しました。風を表す線のアニメーションは風向きを見やすくするためのもので、線が動く速さは実際の風速とは異なります。
