# BORA 화면 개편 기준

2026년 9월 22일에 확인한 자료와 이번 구현의 선택을 기록한다.

## 확인한 자료

- [Webflow 2026 웹 디자인 동향](https://webflow.com/blog/web-design-trends-2026): 서비스 고유의 표현과 일관된 색상 체계. 소개 페이지의 유행을 기상지도 조작부에 그대로 적용하지 않는다.
- [Figma 2026 웹 디자인 동향](https://www.figma.com/resource-library/web-design-trends/): 글자 크기·굵기, 상호작용, 입체 표현. BORA에서는 기상지도와 실제 바람 움직임이 중심이다.
- [Apple WWDC26 Platforms State of the Union](https://developer.apple.com/videos/play/wwdc2026/102/): 배경이 복잡한 화면의 가독성, 조작부와 콘텐츠의 구분, 기기 크기에 따른 배치. 불투명도·대비를 확보한 조작 패널에 적용한다.
- [Material 3 Expressive 연구](https://design.google/library/expressive-material-design-google-research): 주요 동작의 크기·위치·그룹화. 모바일에서는 시간 이동과 자료 선택을 손이 닿는 하단에 둔다. 문서의 실험 결과를 BORA의 성과로 인용하지 않는다.
- [토스 UX Writing, 2026-01-30](https://toss.tech/article/44737): 과장하거나 사용자의 상황을 단정하지 않는 문구, 한 번에 하나의 핵심 전달.
- [토스의 8가지 라이팅 원칙](https://toss.tech/article/21022): 군더더기와 중복 설명 제거. 발행일은 2022년으로, 최신 동향과 구분한다.
- [Met Office 예보 색상표](https://weather.metoffice.gov.uk/learn-about/how-forecasts-are-made/forecast-colour-scales): 같은 값에 같은 색을 쓰는 비교 가능한 색상표. 공식 색상표를 복제하거나 기상청 표준이라고 표시하지 않는다.
- [Zoom Earth 풍속 지도](https://zoom.earth/maps/wind-speed/): 2026-09-22 모바일·데스크톱 화면 확인. 지도 중심 화면, 짧은 색상표, 하단 시간 조작.
- 기상청·ECMWF의 자료 구분과 발표·예측시각은 [기상 UI 조사](forecast-ui-research.md)에 별도로 기록했다.

## 설계와 자체 검토

지도에서 날씨를 비교하고 지역별 예보를 확인하는 서비스다. 데스크톱 관리 화면 같은 넓은 고정 여백과 반복되는 설명을 줄인다. 사용자가 선택한 자료, 단위, 예보 시각은 계속 보여 준다.

처음 검토한 검정 바탕에 강한 포인트색 하나를 쓰는 안은 기상자료와 관계없는 장식이어서 제외했다. 회색 바탕에 파란 선택 표시만 바꾸는 안도 기존 화면과 차이가 작아 제외했다. 최종 방향은 **전체 화면 지도, 작고 명확한 조작부, 기상요소마다 의미가 다른 색상표**다.

| 항목 | 결정 |
| --- | --- |
| 조작부 색 | 흰색 `#FFFFFF`, 밝은 회색 `#F2F4F3`, 본문 `#202523`, 보조문자 `#59615D`, 선택 `#263B37` |
| 지도 바탕 | 바다 `#DFE7E8`, 육지 `#F0F1ED`. 야간 화면은 별도 대비 확인 |
| 자료 색 | 풍속은 밝은 청회색에서 짙은 청색으로 강도를 구분. 기온은 영하의 청색과 영상의 황색·적색을 구분. 미세먼지 등급은 수치·등급명을 함께 표시 |
| 글꼴 | 한글 UI용 SUIT Variable. 숫자는 같은 글꼴의 고정폭 숫자 사용. 장식용 명조·영문 소제목 제외 |
| 데스크톱 | 상단 검색, 왼쪽 자료 선택, 지도 위 짧은 색상표, 하단 예보 시간. 통계는 범례를 펼칠 때 확인 |
| 모바일 | 상단 검색과 현재 자료, 하단 시간·기상요소·자료 종류. 설정은 별도 시트 |
| 문구 | `기온`, `풍향·풍속`, `강수량`, `발표시각`, `예보시각`처럼 익숙하고 정확한 말. 버튼은 누른 뒤 할 일로 이름 붙임 |
| 움직임 | 실제 바람의 방향, 지도 이동, 사용자가 여는 패널에 한정. 동작 줄이기 설정 반영 |

## 검토한 동작

지역 찾기 → 예보 확인, 기상요소 바꾸기 → 범례 읽기, 시간 이동 → 같은 지역 비교, 대기질·CCTV 조회, 조회 실패 → 재시도, 휴대폰 세로·가로 전환, 키보드·확대 글자·밝은 화면·어두운 화면을 실제 브라우저에서 확인했다. README에는 최종 화면과 실제 API 자료를 사용했다. ITS CCTV는 이날 상류 응답이 지연돼 정상 연결 캡처에서 제외했다. 자세한 결과는 [검증 기록](ui-validation-20260922.md)을 참고한다.
