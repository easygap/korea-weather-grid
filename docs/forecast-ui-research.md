조사 기준일: 2026-09-22. 공개된 공식 자료와 실제 운영 화면을 확인했다. 문서의 발행·수정일과 접속 확인일을 구분한다. 예보관 인터뷰나 내부 시스템 사용성 검증을 수행한 것은 아니다.

2026년 자료에서 확인한 방향은 지도 면적, 시간 탐색, 단위와 범례, 읽기 쉬운 글자, 빠른 상호작용이다. 이를 모든 디자인 업계의 유행이라고 일반화하지 않는다. ECMWF는 공개 차트 카탈로그와 공식 ecCharts 사용 문서를 확인했다. 기상청과 Ventusky는 데스크톱·모바일 운영 화면을 직접 확인했다.

## 현재 화면

전체 화면 지도와 작은 조작 패널을 사용한다. 데스크톱은 왼쪽에서 자료를 고르고, 모바일은 아래에서 자료와 시간을 바꾼다. 축약 범례를 누르면 상세 범례와 통계를 확인한다. 한글과 숫자에는 SUIT를 사용하며, 풍속·기온·일사강도 색상은 각각 수치의 의미에 맞게 구성한다.

색상값과 모바일 배치, 2026년 디자인 자료는 [화면 개편 기준](design-direction.md)에 정리했다.

## 용어 기준

| 표시 | 의미 |
| --- | --- |
| 풍향·풍속 | 풍속 색상과 바람 방향을 함께 표시 |
| 강수·적설 | 1시간 강수량·강수형태·1시간 신적설 선택 |
| 일사강도 | 하향단파복사, W/㎡ |
| 발표시각 | 기상청 단기예보의 발표 기준 |
| 모델 초기시각 | 모델 자료에서 제공하는 초기시각 |
| 예측시각 | 자료가 예측하는 실제 시각. 요청과 다를 때 실제 자료 시각을 별도 표시 |
| 관측시각 | 대기질·낙뢰 등 관측자료의 시각. 예보 시간축과 혼합하지 않음 |
| 지도만 보기 | 주변 선택 패널 숨기기. F로 전환, Escape로 복귀 |

내부 코드의 최적화는 유지하되, UI를 바꾸었다는 이유로 데이터 출처·예보 구간·경보 판단을 새로 만들어내지 않는다. 예제 자료는 실제 예보로 표시하지 않는다.

## 검증 결과

최종 테스트와 성능 측정 조건은 [2026-09-22 검증 기록](ui-validation-20260922.md)에 정리했다. 지도 색상과 API 격자값, 발표·예보·관측시각의 구분을 검증한다. 예보관 인터뷰나 예보 정확도 검증을 수행한 것으로 확대 해석하지 않는다.
